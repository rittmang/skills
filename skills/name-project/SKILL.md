# Name a project

Turn a concrete brief into a distinctive, usable name and explain the tradeoffs. This is a creative naming workflow that works without network access.

## Establish the brief

Use the conversation and project context to identify what it does, who it serves, its distinguishing idea, desired tone, and any language or naming constraints. Preserve names or directions the user already likes.

If the purpose is missing, ask one focused question. Otherwise start with stated assumptions instead of requiring a branding questionnaire. Naming recommendations can be evaluated from the brief and known context. If the request also needs domain or social availability, pass the shortlist to `create-company-identity` when available; that skill owns live identity research.

## Develop and compare names

1. Explore a few genuinely different directions: a useful metaphor, an evocative compound, a direct description, or a pronounceable coined word. Choose directions that fit the brief rather than mechanically filling every category.
2. Offer a manageable set of candidates, usually 8–12 for a broad first pass or fewer for a focused request. Give each a short rationale; include pronunciation when it is not obvious. Avoid padding the list with minor spelling variants or unexplained AI-themed suffixes.
3. Shortlist the strongest candidates using audience fit, memorability, ease of saying and spelling, distinctiveness, and room for the project to evolve. Explain meaningful tradeoffs in words; invented numerical precision adds little.
4. Consider obvious conflicts and confusing associations already present in the supplied context. Identify assumptions that affect a candidate's fit without claiming to have researched its availability.
5. Recommend a leading name and a small number of alternatives. Explain which naming constraint would change the recommendation.

When another skill supplies a company brief, return naming directions, rationale, and the shortlist. Let the company workflow perform live identity checks and make the overall identity decision.

## Deliver the decision

Scale the response to the request. A useful result includes the interpreted brief, candidates with rationale, a ranked shortlist, and a recommendation. Present names as creative suggestions rather than verified identities or trademark-cleared names.
